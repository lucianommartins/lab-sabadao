This file lists the active maintainers and core governance members of the Google Gemma `gbench` open-source repository.

## Maintainer responsibilities

* Reviewing pull requests against Golden Set (`16/16 PASS`) and coefficient of variation (`CV% <= 5.0%`) invariants.
* Maintaining engine parity across vLLM C++/CUDA bindings and remote HTTP REST endpoints.
* Curating standard workload campaigns, evaluation datasets, and interactive tutorial notebooks.
* Publishing release candidates and managing repository governance.
